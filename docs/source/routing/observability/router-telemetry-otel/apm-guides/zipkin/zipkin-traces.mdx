Enable and configure tracing for [Zipkin](https://zipkin.io/) in GraphOS Router or Apollo Router Core.

For general tracing configuration, refer to [Router Tracing Configuration](/router/configuration/telemetry/exporters/tracing/overview).

## OTLP configuration

<Note>
    The native Zipkin exporter has been removed in Router 3.0. Zipkin supports OTLP ingestion, and OpenTelemetry has [deprecated native Zipkin exporters](https://opentelemetry.io/blog/2025/deprecating-zipkin-exporters/) in favor of OTLP. Export traces to Zipkin using the OTLP exporter as shown below.
</Note>

Zipkin supports OTLP ingestion via [zipkin-otel](https://github.com/openzipkin-contrib/zipkin-otel). Configure the OTLP exporter to point at your Zipkin OTLP endpoint:

```yaml title="router.yaml"
telemetry:
  exporters:
    tracing:
      otlp:
        enabled: true
        endpoint: "http://${env.ZIPKIN_HOST}:9411"
        protocol: http
```

This sends traces to Zipkin using the OTLP protocol.

See [OTLP configuration](/router/configuration/telemetry/exporters/tracing/otlp#configuration) for more details on settings.

## Zipkin propagation

Zipkin (B3) trace-context propagation remains supported independently of the exporter. See [trace context propagation](/router/configuration/telemetry/exporters/tracing/propagation/overview) for details.
